# Changelog

All notable changes to this project will be documented in this file.

The format follows Semantic Versioning.

---

# [2.0.0] - Initial Framework Release

## Added

- Introduced modular project initialization architecture.
- Added Project Orchestrator as the central workflow controller.
- Added Project Bootstrapper for project initialization and PRD generation.
- Added Discovery Engine for adaptive project discovery.
- Added deterministic state-based workflow.
- Added documentation for architecture and execution flow.
- Added workflow examples across multiple domains.

## Changed

- Reframed the system from a PRD generator into a complete project initialization framework.
- Introduced orchestration-driven architecture.
- Separated discovery, validation, and specification generation responsibilities.

## Design Improvements

- Explicit component responsibilities.
- Centralized workflow control.
- Model-agnostic architecture.
- Reduced dependency between components.
