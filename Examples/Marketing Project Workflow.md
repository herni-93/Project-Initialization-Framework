# Marketing Project Workflow

## Initial Request

> "I need a launch campaign for a new AI product."

---

# Framework Initialization

The Project Orchestrator receives the request and delegates project initialization to the Project Bootstrapper.

The Bootstrapper evaluates the available information and determines that several critical project details are missing.

Before defining deliverables or planning execution, additional discovery is required.

---

# Adaptive Discovery

The Project Bootstrapper delegates control to the Discovery Engine.

The Discovery Engine conducts an adaptive interview focused on understanding the business context rather than following a predefined questionnaire.

Example questions may include:

- What is the product being launched?
- Who is the target audience?
- What are the campaign objectives?
- Which marketing channels will be used?
- What budget or timeline constraints exist?
- Which KPIs will determine success?

The interview adapts dynamically based on each response and ends once the project can be clearly defined.

---

# Validation

The Discovery Engine generates an executive summary describing the campaign.

The summary is presented to the user for approval.

If additional clarification is required, only the relevant sections are revisited before generating a new summary.

Once validated, control returns to the Project Bootstrapper.

---

# PRD Generation

Using the validated project definition, the Project Bootstrapper generates a structured Product Requirements Document (PRD).

The document captures the campaign objectives, constraints, expected deliverables, success criteria, and execution requirements.

Control is then returned to the Project Orchestrator.

---

# Result

✅ Marketing project successfully initialized

✅ Validated campaign definition

✅ Structured PRD generated

✅ Campaign ready for execution
