# Research Project Workflow

## Initial Request

> "I want to investigate how companies are adopting AI automation in their internal processes."

---

# Framework Initialization

The Project Orchestrator receives the request and delegates project initialization to the Project Bootstrapper.

The Bootstrapper evaluates the available information and determines that the research scope, methodology, and expected outcomes are not yet defined.

Additional discovery is required before creating the project specification.

---

# Adaptive Discovery

The Project Bootstrapper delegates control to the Discovery Engine.

The Discovery Engine conducts an adaptive interview focused on understanding the research objective and defining the project boundaries.

Example questions may include:

- What is the main objective of the research?
- Which companies, industries, or markets should be analyzed?
- What type of information is required?
- What sources should be considered?
- What methodology should be used?
- What format should the final research output have?

The interview adapts according to the responses and stops once the research project has a clear definition.

---

# Validation

The Discovery Engine generates an executive summary describing:

- Research objective
- Scope
- Methodology
- Expected deliverables
- Constraints
- Success criteria

The summary is presented to the user for validation.

If changes are required, only the affected areas are revisited.

Once approved, control returns to the Project Bootstrapper.

---

# PRD Generation

Using the validated research definition, the Project Bootstrapper generates a structured Product Requirements Document (PRD).

The PRD defines the research project requirements, expected outputs, execution phases, and validation criteria.

Control is then returned to the Project Orchestrator.

---

# Result

✅ Research project successfully initialized
