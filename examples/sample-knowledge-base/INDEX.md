# Knowledge Base Index

Example of an existing knowledge base the Knowledge Connector can read.
Replace it with your own: the connector only reads, it never writes here.

- `SYSTEM.md`: global working instructions (a `CLAUDE.md` or `AGENTS.md` works the same way).
- `system-prompts/`: reusable system prompts.
- `skills/`: skills, one folder per skill with a `SKILL.md`.
- `workflows/`: step-by-step workflows.
- `knowledge/`: notes and decisions.
- `graph.json`: small knowledge graph linking the notes above.
